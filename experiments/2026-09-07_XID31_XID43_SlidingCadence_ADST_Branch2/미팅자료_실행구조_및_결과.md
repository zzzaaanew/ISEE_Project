# 2026-09-07 미팅자료 — XID 31·43 통합 Telemetry 예측 파이프라인

## 1. 이번 실행의 결론

이번 실험은 XID 31과 XID 43을 하나의 이진 타깃으로 통합하고, 동일한 held-out test 구간에서 fixed split, Sliding Training, ADST를 비교했다.

가장 높은 PR-AUC는 Branch 2의 Historical Logistic + ADST 조합에서 나왔다.

- PR-AUC: **0.07213**
- ROC-AUC: **0.79618**
- test 양성률: **0.7253%**
- 자연 양성률 대비 normalized PR-AUC: **9.94배**

ADST는 재학습 주기를 6시간으로 고정하고, 매 rolling origin에서 Window만 7·14·21일 중 선택했다. 64개 origin에서 7일 30회, 14일 12회, 21일 22회가 선택되었다.

이번 결과는 HPO나 Calibration을 적용하기 전의 비교 결과다. 따라서 다음 단계는 PR-AUC 기준으로 Branch 2 Historical Logistic을 1순위 후보로 선정하고, validation 기반 HPO를 수행하는 것이다.

## 4. 코드 실행 구조

현재 실행본은 \`ML/pipeline.py\` 하나로 데이터 처리, 학습, 평가, Excel 저장을 수행한다.

~~~text
Seren raw XID_ERRORS.csv
        │
        ├─ 30초 연속 기록 병합
        ├─ 최초 onset 추출
        └─ XID 31 OR XID 43 binary target
        │
        ├─────────────── Seren 5분 Parquet: mean / observation
        ├─────────────── Seren 15초 raw CSV: 5분 std 재계산
        └─────────────── branch2_context_features.parquet
                        │
              Time_5m + gpu_id left join
                        │
          1시간 입력 + 직전 10분 cutoff
                        │
          24시간 미래 onset label 생성
                        │
        chronological split + 36시간 purge
                        │
     ┌──────────────────┴──────────────────┐
     │                                     │
 Branch 1: Temporal                 Branch 2: Historical/Context
 LR / Extra Trees /                 Historical Logistic /
 1D-CNN / Tiny-TCN                  Historical GBDT
 rank-mean ensemble                 XID history + context features
     │                                     │
     └───────────────┬─────────────────────┘
                     │
       split 또는 rolling test scoring
                     │
     Split / Sliding 6h·24h·3d / ADST 6h
                     │
       Branch_1 Excel + Branch_2 Excel
~~~

### 4.1 데이터 및 라벨 처리

1. raw \`XID_ERRORS.csv\`를 chunk 단위로 읽어 GPU별 XID 기록을 재구성한다.
2. 같은 XID가 30초 이내 이어지면 하나의 episode로 병합하고 최초 시각을 onset으로 사용한다.
3. XID 31 또는 XID 43 onset이 향후 24시간 안에 존재하면 해당 GPU-decision을 양성으로 라벨링한다.
4. 이미 장애가 진행 중인 구간과 onset이 불확실한 구간은 학습·평가 eligible population에서 제외한다.
5. 5분 Parquet에서 평균·관측 여부를 읽고, raw 15초 CSV에서 GPU utilization, temperature, power, framebuffer usage의 5분 표준편차를 다시 계산한다.
6. 입력은 12개 5분 bucket으로 구성하며, 마지막 10분은 XID 기록 지연에 의한 사후 신호 누출을 피하기 위해 제외한다.

### 4.2 Train / Validation / Test

- 전체 유효 decision time을 시간순으로 60/20/20 분할한다.
- 분할 경계 주변 36시간은 purge하여 horizon 겹침에 의한 누출을 줄인다.
- 고정 split에서는 train decision time 720개, validation decision time 240개를 사용한다.
- train은 계산량을 제한하기 위해 양성 전체와 음성 최대 4배를 사용한다.
- validation은 ADST Window 선택과 CNN/TCN 검증에 사용하며, eligible한 전체 음성까지 포함한다.
- test는 재학습에 사용하지 않고, 동일한 held-out 구간에서 각 실행 정책의 누적 예측을 비교한다.

### 4.3 Branch 1: Temporal Branch

입력 시계열의 통계적·국소적 패턴을 이용한다.

- Logistic Regression
- Extra Trees
- 1D-CNN
- Tiny-TCN
- 위 네 모델의 rank-mean parallel ensemble

Branch 1의 ensemble은 각 모델의 raw probability를 단순 평균하지 않고, test 시점별 GPU 순위를 평균해 상대 위험도를 계산한다.

### 4.4 Branch 2: Historical Branch

1시간 telemetry와 context를 요약한 표에 XID 이력을 결합한다.

- Historical Logistic: 선형 기준 모델
- Historical GBDT: 비선형 context 모델
- 이력 변수: 최근 30일 XID 발생 횟수, 직전 XID 이후 경과 일수
- telemetry 요약: mean, std, last, min, max
- context 요약: 평균값과 마지막 값

ADST Window 선택기는 Branch 2 Historical Logistic 하나로 고정했다. 각 origin에서 7·14·21일 후보를 각각 train/validation하고 validation PR-AUC가 가장 높은 Window를 선택한다. 선택된 Window로 Branch 1과 Branch 2 전체 모델을 다시 학습한 뒤 다음 test 구간을 평가한다.

## 5. 실행 정책 비교

| 실행 유형 | 학습 Window | 재학습 주기 | Window 선택 |
|---|---:|---:|---|
| Split | 시간순 train 전체 | one fit | 고정 split |
| Sliding 6h | 15일 | 6시간 | 고정 |
| Sliding 24h | 15일 | 24시간 | 고정 |
| Sliding 3d | 15일 | 3일 | 고정 |
| ADST | 7/14/21일 후보 | **6시간 고정** | Branch 2 validation PR-AUC로 동적 선택 |

ADST에서 동적으로 바뀌는 것은 Window뿐이다. 재학습 주기, horizon, 입력 길이, 데이터 분할, 모델 하이퍼파라미터는 이번 비교에서 바꾸지 않았다.

## 6. 성능 결과

### 6.1 Branch 2 — 주요 비교 결과

| 실행 유형 | Historical Logistic PR-AUC | Historical Logistic ROC-AUC | Historical GBDT PR-AUC | Historical GBDT ROC-AUC |
|---|---:|---:|---:|---:|
| Split | 0.03351 | 0.80634 | 0.01775 | 0.76694 |
| Sliding 6h | 0.04936 | 0.78595 | 0.03797 | 0.82094 |
| Sliding 24h | 0.04927 | 0.78933 | 0.04003 | 0.83030 |
| Sliding 3d | 0.04674 | 0.79147 | 0.03467 | 0.82270 |
| ADST | **0.07213** | 0.79618 | 0.05190 | **0.83956** |

해석:

- PR-AUC 기준 최고 모델은 ADST Historical Logistic이다.
- ROC-AUC 기준 최고 모델은 ADST Historical GBDT다.
- 양성률 0.7253% 자체가 매우 낮으므로 raw PR-AUC만 보지 않고 normalized PR-AUC도 함께 봐야 한다.
- ADST Historical Logistic의 normalized PR-AUC는 9.94이며, 자연 양성률 대비 약 9.94배의 ranking 성능이다.
- ADST의 개선은 Branch 2에서 뚜렷하고, “짧은 재학습 주기 자체”보다 이력·context와 Window 적응의 결합 효과로 해석하는 것이 타당하다.

### 6.2 Branch 1 — Temporal 모델 비교 결과

| 실행 유형 | LR PR-AUC | Extra Trees PR-AUC | 1D-CNN PR-AUC | Tiny-TCN PR-AUC | Parallel Ensemble PR-AUC |
|---|---:|---:|---:|---:|---:|
| Split | 0.01040 | 0.01043 | 0.01160 | 0.01063 | **0.01185** |
| Sliding 6h | 0.00856 | 0.00923 | 0.00950 | 0.01000 | **0.01136** |
| Sliding 24h | 0.00895 | 0.00960 | **0.01138** | 0.00981 | 0.01102 |
| Sliding 3d | 0.00884 | 0.00984 | 0.01030 | 0.01007 | **0.01159** |
| ADST | 0.00842 | 0.01009 | 0.00976 | 0.00917 | **0.01111** |

Branch 1에서는 ADST가 Split ensemble을 넘지 못했다. 따라서 현재 데이터에서는 telemetry 단독 시계열 패턴보다 XID 이력과 context 변수가 예측에 더 유용할 가능성이 크다.
