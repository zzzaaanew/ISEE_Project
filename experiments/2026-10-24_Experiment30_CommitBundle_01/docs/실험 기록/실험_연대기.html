Experiment 10 = Equal-weight Branch 1 Cascade + fixed Branch 2 Sliding Training

[요약]

  • 이번 Experiment가 검증하는 질문: Branch 1에 동일 가중치 Parallel Ensemble과 Cascade를 적용하고, Branch 2는 ADST 동적 선택 없이 고정 7일 Sliding Training으로 유지할 때 전체 rolling 평가 성능과 ADWIN train-window 전환이 어떻게 나타나는가.
  • 이전 Experiment와의 연결: 직전 fixed-family-weight 실행에서 Branch 1 ADWIN이 21일 최대 window에 포화되어 expand가 실질적 변화를 만들지 못했다. 이번에는 초기 window를 14일로 낮추고 민감도를 완화해 실제 확장 가능성을 검증했다.

[실행]

  • 유지한 기준: All-XID 통합 onset 타깃, 30일 warm-up, 24시간 rolling/retrain, 24시간 horizon, 오류 직전 10분 제외, 36시간 purge, 30분 scoring, 전체 GPU-time population.
  • Branch 1 변경: 1시간 input, Logistic·Extra Trees·HistGradientBoosting·CNN 4개 family의 동일 가중치 0.25 parallel ensemble, soft residual hardness-gated Cascade.
  • Branch 1 ADWIN: 7·14·21일 후보, 초기 14일, delta 0.05, 최소 feedback 4개, 2회 연속 trigger, cooldown 1 cycle. label-matured 30분 Branch 1 log-loss를 감시했다.
  • Branch 2: xid_count_30d, days_since_xid History-only 입력, 7일 고정 Sliding Training. Branch 2 ADST·ADWIN·recency adaptation은 적용하지 않았다.
  • Fusion: p_fused = 0.5 × p_B1 + 0.5 × p_B2.
  • 평가: terminal held-out은 adaptation과 선택에서 제외하고, warm-up 이후 64개 rolling origin의 full-period 결과를 사용했다.
  • 실행 진입점: ISEE_Project_GitHubBase/ML/run_experiment6_30m_adwin_b1_equal_cascade_b2_sliding_v2.py.
  • 최종 manifest writer 정정 진입점: ISEE_Project_GitHubBase/ML/run_experiment6_30m_adwin_b1_equal_cascade_b2_sliding_v3.py.
  • 산출물: ISEE_Project_GitHubBase/experiments/2026-09-28_All-XID_Experiment6_30m_ADWIN_B1EqualCascade_B2Sliding_01/.
  • 재현 조건: seed 20260905, 64개 state, 전체 score export, 실행 상태 COMPLETED.

[분석]

  • 관찰: 초기 14일 설정에서는 안정성 규칙에 의해 state 9 이후 21일로 확장됐다. raw ADWIN drift trigger는 delta를 0.05로 완화했음에도 발생하지 않았다.
  • 관찰: 동일 평가계약의 직전 실행 대비 Fusion PR-AUC는 +7.1%, Branch 1 PR-AUC는 +2.0%였지만 Fusion ROC-AUC는 -0.3%, Recall@100과 Lift@100은 각각 약 -0.7%였다.
  • 해석: 동일 가중치와 Cascade alpha 재선택은 PR-AUC 평균을 높였지만, 모든 origin에서 Branch 1 또는 Branch 2보다 우월한 구조는 아니다. PR-AUC 평균은 특정 고양성 구간의 영향을 받으므로 중앙값과 origin별 승률을 함께 봐야 한다.
  • 해석: 이번 ADWIN은 hold 포화 문제는 일부 해소했지만, 실제 drift 기반 축소는 검증하지 못했다. 현재 feedback log-loss stream에서 통계적 shift가 검출되지 않았거나, PR-AUC 변화와 log-loss 변화가 일치하지 않았을 가능성이 있다.
  • 결정: Equal-weight Cascade + Branch 2 fixed Sliding 조합은 비교 후보로 보존한다. 최종 우월 모델로 확정하지 않는다.
  • 결정: Branch 2에는 ADST 동적 선택을 적용하지 않은 현재 계약을 유지한다.
  • 한계: 이번 비교는 직전 실행과 1시간 input·lambda·Branch 2 조건은 공유하지만, Branch 1 family weighting과 ADWIN controller가 달라 직접적인 단일 원인 효과로 해석할 수 없다.
  • 검증 보정: 실제 계산 feature grid는 [1]이었다. inherited rolling writer가 state manifest에 [1,6,24]를 표시한 문제를 확인했고, score parquet와 metric CSV는 변경하지 않은 채 model_state_manifest.parquet의 표시값을 [1]로 정정했다.

  2. ADWIN 축소를 최종 방법론으로 주장하지 않고, raw trigger 0회와 14일→21일 확장 결과를 별도 보고한다.
  3. ML 후보가 확정되기 전에는 BLOX를 실행하지 않는다.
  4. 다음 실험에서는 성능 선택과 ADWIN 민감도 선택을 분리해, 사전에 정한 development 기준으로 채택 여부를 결정한다.

Experiment 11 = Han ADST + 4-model light Cascade + reliability Fusion

[요약]

  • 관련 목표: G-004, G-007, G-008.
  • 한유형 2f7914e 기준의 30분 GitHub-base rolling evaluator를 유지하면서 Branch 1에 Han-style ADST train-window controller와 4개 경량 모델 Cascade를 적용했다.
  • Branch 2는 History-only 21일 고정 Sliding Training으로 유지했고, ADWIN·BLOX·Parallel Branch 1은 사용하지 않았다.
  • 고정 Lambda 대신 최근 Branch 성능·안정성·하락률을 이용한 past-only reliability Fusion을 적용했다.

[실행]

  • 입력: 현재 All-XID 데이터, 1,992 GPU score population, XID 2,425개.
  • split/evaluation: 30일 warm-up, warm-up 이후 64개 rolling origin, 24시간 horizon, 24시간 retrain, 30분 scoring, 36시간 purge, 오류 직전 10분 제외.
  • Branch 1: Logistic Regression, Extra Trees, HistGradientBoosting, CNN의 4-model light Cascade; 1시간 입력 contract.
  • Branch 1 ADST: 7/14/21일 후보, 초기 14일, Han-style momentum skip/trigger window controller. ADWIN은 미사용.
  • Branch 2: strict History-only, 21일 고정 Sliding Training.
  • Fusion: 최근 3개 origin reliability, 2회 hysteresis, B1 weight 0.2~0.8, origin당 최대 0.1 변경.
  • 재현 조건: seed 20260905, negative ratio 10, threads 4.
  • 실행 진입점: ISEE_Project_GitHubBase/ML/run_experiment11_30m_han_adst_b1_light_cascade_b2_sliding.py.

  • smoke 단계에서 B1 half-life 0과 Cascade OOF block 수, 학습·scoring feature contract 문제를 발견해 수정했다. 최종 실행은 수정 후 1개 origin smoke를 통과하고 full run을 완료했다.

  • 결정: 이번 구조는 최종 우월 모델로 확정하지 않고, 신뢰도 기반 Fusion 후보로 보존한다. BLOX 연결은 추가 비교 후 진행한다.

Experiment 12 = Temporal MoE 저장 점수의 Top-100 검증과 후보 합집합 = 보충 기록

[요약]

  • Experiment 11의 B1 경량 Cascade·Han ADST와 B2 History-only 21일 Sliding을 유지하고, 원 실행에서는 30분 Temporal MoE Fusion을 사용했다. 후속 저장 점수 분석에서 전체 GPU Top-100을 동일한 분모로 비교하고 B2-anchored 후보 합집합 재정렬을 탐색했다. 이 항목은 기존 실행을 2026-10-04에 뒤늦게 기록한 것이다.

[실행]

  • 목표 G-007·G-008. All-XID onset, 24시간 horizon, 10분 feature cutoff, 36시간 purge, 30일 warm-up 이후 64개 rolling origin, 30분 판단, 1,992 GPU. 별도 terminal held-out에서 선택하지 않았다.
  • 저장된 전체 GPU B1/B2 점수 64개 part와 원본 5분 grid·onset 라벨만 사용했다. 재정렬기는 성숙한 과거 OOF 7일 학습·7일 검증에서 M={150,250,400}, N={50,100,200}, K={0,5,10}, 위험비={1.0,1.2}를 선택하고 증거가 없으면 B2로 복귀했다.
  • 원본 실행 진입점: ISEE_Project_GitHubBase/ML/run_experiment12_30m_temporal_moe_b2_anchor.py. Top-100 검증과 재정렬 진입점: ML/evaluate_experiment12_top100.py, ML/evaluate_experiment12_candidate_union.py. 재정렬 seed 20260905; 결과 experiments/2026-10-01_Experiment12_B2Anchored_Union_Rerank_01/.

[결과]

  • 전체 64 origin, 3,053개 판단 시점, 6,081,576 GPU-time 중 양성 52,945개였다. B2 Top-100 적중은 8,335개(Recall 0.157428, 양성 시점 NDCG 0.079820), 원래 Temporal MoE Fusion 적중은 7,078개(Recall 0.133686, NDCG 0.075425)였다.
  • 후보 합집합은 8,411개 적중(Recall 0.158863, NDCG 0.080190)으로 B2보다 76개 많았다. 총 12,936번 교체했고 36개 origin에서 활성, 28개에서 B2 복귀했다. B2 대비 origin별 15승·46무·3패였다.

[분석]

  • 관찰: 기존 Fusion의 origin 평균 Recall 우위는 전체 GPU-time 포착 우위가 아니었다. 후보 합집합의 순증가 76개는 작고 손실 origin도 남았다.
  • 결정: 후보 합집합은 탐색 후보로 보존하되 최종 우월 모델로 채택하지 않는다. 저장된 B1의 ADST 피드백이 라벨 성숙 전에 영향을 받았을 가능성과 같은 XID 에피소드의 반복 GPU-time 집계를 분리해야 한다.
